# Upload instructions

1. Extract this ZIP with Windows Extract All.
2. Upload README.md and the entire assets/ folder to the root of your GitHub profile repository: tayyabXtreme/tayyabXtreme. Keep the folder structure.
3. Also upload INTER-LICENSE.txt, DEJAVU-LICENSE.txt, SIMPLE-ICONS-LICENSE.txt and SOURCES.md so provenance travels with the assets.
4. preview.html is an optional local browser preview; upload it too if you want it in the repository.

## Exact package files to upload

- README.md
- assets/hero.svg
- assets/about-life.svg
- assets/stack.svg
- assets/id-dashboard.svg
- assets/connect.svg
- assets/id.png
- assets/right_pointing.png
- assets/display.woff2
- assets/mono.woff2
- assets/icons/ (all 13 source SVG icons)
- INTER-LICENSE.txt
- DEJAVU-LICENSE.txt
- SIMPLE-ICONS-LICENSE.txt
- SOURCES.md

Open preview.html after extracting the entire archive. The SVGs need no internet access. Animation playback depends on the viewer; reduced-motion users see a complete still version.

VALIDATION.md and render_checks/ document the verification and do not need to be uploaded.
